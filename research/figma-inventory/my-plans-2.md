## Pattern candidates

### Plan catalogue list (L1, dark hero)
- **When:** Captain must browse and compare several earning plans and pick one to inspect
- **Structure:** Dark navy hero (circle back, MY PLAN lottie logo, "Choose Your Earning Plan") > section dividers ("₹0 To Start", "Recharge Plans") > stacked plan cards (persona tag pill, eyebrow, big value + struck old value, plan type + (Free/Paid Plan), play-video icon, secondary "View Details" button) > active plan card with green border + "Active Plan" badge
- **Components:** Buttons, Detail Tag, Icon Only Button, header lottie ("final" instance), local plan card "Component 1"
- **Evidence:** [3617:12919](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=3617-12919), [5603:35850](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=5603-35850), [4835:19523](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=4835-19523), [3558:8195](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=3558-8195)
- **Variations:** light-body refresh on L1 design page (5603:35850); performance-grouped with locks (Quality BYOB); CARD OPTIONS page tests no-CTA / play icon / watch-video CTA / no-details cards
- **Conflicts:** CTA style differs: black outline pill (L2 page) vs blue outline pill with chevron (L1 design); hero dark vs light body

### Plan detail + sticky activate (L2)
- **When:** Captain needs to understand one plan (what is included / deducted) before committing
- **Structure:** InternalPageHeader("Plan Details") > summary card (tag pill, title, subtitle) > video ingress card > inclusion list card (green plus/orange minus rows) > Know More check list > sticky footer: info note + primary yellow "Activate Plan"
- **Components:** InternalPageHeader, Buttons, Plus/Minus_Circle_Filled, local video ingress, local note
- **Evidence:** [3617:15300](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=3617-15300), [4835:22866](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=4835-22866), [3788:5642](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=3788-5642)
- **Variations:** Quality BYOB adds performance-ladder card; MG plans add zone chip/time window; plan-switch shows "starts after current plan ends" note

### Radio plan selector with sticky summary footer (Bike SaaS)
- **When:** Captain chooses exactly one of several priced options and confirms
- **Structure:** InternalPageHeader(title, Help chip) > promo hero banner > grouped sections (title + audio explainer icon) of radio rows (title, meta, price right) > Important info note > T&C bullets > sticky footer (PLAN SELECTED label + name + price, primary yellow CTA)
- **Components:** InternalPageHeader, Radio Button, Buttons, local Plan Option Card/Row, Badge Pill
- **Evidence:** [7469:20337](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7469-20337), [7469:20436](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7469-20436), [8058:16376](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=8058-16376)
- **Variations:** single plan vs multiple sections; active plan state replaces selector at top
- **Conflicts:** L1 list uses cards + View Details instead of radio + sticky; two different selection idioms for the same "pick a plan" job

### Activation confirmation modal
- **When:** Immediately after an irreversible/important activation succeeds
- **Structure:** Dimmed source page > centred white card: green check, "<Plan> Active", one-line body, primary yellow "Okay"; preceded by spinner card "Please wait"
- **Components:** Buttons, Modal (Runway)
- **Evidence:** [7469:22236](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7469-22236), [3617:13542](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=3617-13542), [4835:18820](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=4835-18820)
- **Variations:** loading spinner card; video modal
- **Conflicts:** Uses centred modal while result-of-window uses bottom sheet

### Active progress card (target tracker)
- **When:** Captain has an active goal (earnings/rides/time) and needs status at a glance
- **Structure:** Card: status tag (Active/Completed/Upcoming) + plan name + fee; primary metric "₹x/₹500" with linear bar; secondary segmented ride bar "6/9 rides"; status line with icon (green check / red x / yellow)
- **Components:** Tag, local Tracker card component set (7979:16531), Active plan card (7666:16018)
- **Evidence:** [7469:20601](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7469-20601), [7555:15884](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7555-15884), [7555:16001](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7555-16001), [7125:18268](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7125-18268), [7557:17351](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7557-17351)
- **Variations:** home collapsible version vs plan page version; countdown timer for unlimited; ring progress explored in kitchen (8245:26447)
- **Conflicts:** colour semantics: blue progress (home) vs green (plan page)

### Outcome bottom sheet with tinted header
- **When:** End of a plan window – tell the captain the financial outcome
- **Structure:** Dimmed home > close X > sheet with tinted top (green confetti success / yellow warn / blue neutral) showing card snapshot > bold title with amount > body > full-width yellow OK
- **Components:** BottomSheet, Buttons, Tracker card
- **Evidence:** [7209:17764](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7209-17764), [7125:19525](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7125-19525), [7124:17960](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7124-17960), [7125:23160](https://www.figma.com/design/6QRvGOUAYtTm6T6L6VTnxR/?node-id=7125-23160)
- **Variations:** fee charged / cashback got / cashback missed / no fee

### Loss-aversion nudge banner inside existing card
- **When:** Show missed money and a switch-plan CTA on Earnings / Order details
